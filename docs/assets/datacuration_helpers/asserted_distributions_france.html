Asserted distributions with unspecified "France"

Each row is an asserted distribution whose geographic area is the bare Country-level France (ISO FR), with no territory specified. In this project every distribution should point to either a named French overseas territory (Guadeloupe, Martinique, French Guiana, Réunion, Mayotte, New Caledonia, French Polynesia, etc.) or to mainland European France — an unspecified "France" needs to be corrected to mainland France (or, if the record is actually about an overseas territory, to that territory).
This deliberately does not flag the TDWG Level 3/4 "France" regions (WGSRPD scheme): those already exclude Corsica and every overseas department/territory by design, so they aren't ambiguous.
The URL leads directly to the "New/Edit Asserted Distribution" task for that record, where you can change its geographic area. A fixed record drops off the list on the next refresh.
