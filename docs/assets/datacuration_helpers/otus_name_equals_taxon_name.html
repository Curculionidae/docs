OTUs whose name duplicates the taxon name

Each row is an OTU that has both a Name and a Taxon name that are the same name bar authorship (OTU name Acer platanoides, taxon name Acer platanoides L.). Such OTUs are hidden from the TaxonPages search bar — open the edit page and clear the OTU Name field (keep the taxon name), or delete the OTU if it carries no data. A fixed OTU drops off the list on the next refresh. Not limited to plants.
