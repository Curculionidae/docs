# Annotations: Tags, Topics & Data Attributes

## About

Tags, Contents and Data Attributes can be attached to various data objects in TaxonWorks via the Radial Annotator {radial-annotator}.

| TaxonWorks term | What it does | Attached to |
|---|---|---|
| **Keyword** (applied as a *Tag*) | Flags a record with a single reusable label | almost any record |
| **Topic** | Says what a cited source, or a block of text, is *about* | Citations, Content |
| **Predicate** (the name of a *Data attribute*) | The name half of a custom *name → value* fact | almost any record |

Manage the terms in TaxonWorks under **Tasks → Manage controlled vocabulary terms**.

## Contents
**Contents** are longer texts that are used to convey free-text information. Usually we apply them to an OTU, either via the Quick Forms radial {quick-forms}, or via task **Content editor**.  
Note that Contents need to be published to be visible on TaxonPages. Use the Publish/Unpublish toggle.  
It is possible to add depictions, citations and more annotations, but they are currently not read by TaxonPages (needs confirmation).

## Color conventions
- Biological Associations: #254d0d (e.g. {keyword:Endophagous})
- Asserted Distribution: #ff8800 (e.g. {keyword:Endemic})
